# UI/UX & A11y Checklist

Краткий чеклист для ревью интерфейсов (Next.js / React):

- Контраст и цвета: основные тексты ≥ 4.5:1, вторичные ≥ 3:1; использовать дизайн‑токены (цвет, spacing, radius) вместо хардкода.
- Фокус и клавиатура: `:focus-visible` стили у всех интерактивов; навигация табом без ловушек; `Escape` закрывает оверлеи/дроверы/поиск.
- Роли и aria: один `h1` на страницу; логическая иерархия `h2/h3`; для поиска `role="combobox"` + listbox/options; `aria-current="page"` для активной навигации; `role="alert"` для ошибок форм.
- Изображения: осмысленный `alt` (бренд/модель/контекст); `placeholder="blur"` + `blurDataURL` для LCP‑блоков; fallback skeleton, если нет src.
- Skeletons и лоадеры: анимированный shimmer, `aria-busy`/`role="status"`; не блокировать клавиатуру; учитывать `prefers-reduced-motion`.
- Ошибки и пустые состояния: человекочитаемые сообщения, CTA “Попробовать поиск / Сбросить фильтры”; для non-blocking уведомлений — `ToastContainer`.
- Формы: единый `FormField` (label + `aria-describedby` + ошибки с `role="alert"`); inline‑валидация с понятными текстами; disable+spinner на первичных CTA.
- Медиаконтролы: слайдеры/видео управляемы с клавиатуры, пауза при потере фокуса; авто‑плей озвучен `aria-live="off"` или отключён.
- Сохранение контекста: фильтры/сортировка — сохранять в `sessionStorage`, очищать по CTA “Сбросить”.
- Проверки перед релизом: один `h1`, работа таб‑цикла, контраст ключевых текстов, подсказки для поиска, корректные `aria-label` у CTA, skeleton вместо “прыгающих” layout.
